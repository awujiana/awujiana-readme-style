## 🌐 多语言支持

当前提供**简体中文**版本；其他语言的可用状态以顶部语言徽章为准（绿色「当前」/ 蓝色「切換」/ 灰色「待补」）。

> 新增语言：复制 `README.md` 为 `README.<locale>.md` 并翻译，在 `scripts/badges.config.json` 的 `languages` 中登记，然后运行 `python scripts/update_badges.py`。
