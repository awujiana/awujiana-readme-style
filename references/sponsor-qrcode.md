# 赞助码（赞赏码）规范

> 赞助是**可选增强**，不是必选项。开源项目可自愿在 README 中放置赞赏码，支持作者的持续维护。

## 位置与顺序

固定顺序：`🙏 参考与致谢` → `💰 赞助` → `🔗 关联仓库` → `📮 作者联系方式` → `📄 开源协议`。

- 放在**底部强制三节之前**，**不得**插入三节之间。
- 章节数 ≥6 时，须在目录（TOC）中同步增加条目，锚点用 GitHub 自动锚点 `#-赞助`。
- 数据仓库同样适用，位置一致。

## 图片规格

| 项目 | 约定 |
| --- | --- |
| 存放位置 | 本地 `assets/sponsor-qrcode.jpg`（推荐，随仓库发布）；或稳定图床外链 |
| 命名 | 小写英文 + 连字符：`sponsor-qrcode.jpg` |
| 尺寸 | 建议正方形，宽度 200–260px（用 `width` 属性限宽） |
| 格式 | 微信赞赏码为 `jpg` / `png`；矢量示意可用 `svg` |
| 外链要求 | 可匿名访问、未开防盗链；关键图保留本地备份 |

## 推荐写法

用 `<div align="center">` 包裹并限宽居中展示，同时给出文字说明（图片加载失败时仍可理解）：

```markdown
## 💰 赞助

如果这个项目对你有帮助，欢迎请我喝杯咖啡 ☕

<div align="center">
<img src="assets/sponsor-qrcode.jpg" alt="微信赞赏码" width="220" />

**微信赞赏码**
</div>

> 赞赏完全自愿，不影响你使用本项目的任何功能，也不会获得额外的优先支持。
```

> `alt` 文本写清平台（如「微信赞赏码」），利于无障碍阅读与图片失效时的可理解性。

## 措辞要求

- 说明**自愿**性质，不得暗示「赞助才能获得支持」或「不赞助即降级」。
- 建议保留免责说明：赞助不影响功能使用，也不提供额外优先支持。
- 不夸大收益承诺，不写「赞助即成为会员 / 永久支持」等无法兑现的表述。
- 赞赏渠道不止一个时，用列表并列，注明各自平台。

## 禁止事项

- **不得**放入 Release Notes（该文档要求短小精悍，不设徽章、目录与底部信息区）。
- **不得**放在顶部徽章区或 AI 声明之前。
- **不得**用赞赏码遮挡或替代必填的协议、联系方式信息。

## 替换占位图

模板自带的 `assets/sponsor-qrcode.jpg` 是占位图，发布前替换为作者自己的赞赏码：

```bash
# 用自己的赞赏码覆盖占位图
cp /path/to/my-sponsor-qrcode.jpg 输出readme/assets/sponsor-qrcode.jpg
```

或改用图床外链，把 `<img src>` 换成完整 URL。
